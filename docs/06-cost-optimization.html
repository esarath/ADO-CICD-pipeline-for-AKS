6.2 Why these choices

save ~90% Spot node pool

All app workloads carry a toleration for the spot taint and prefer spot nodes. spotMaxPrice: -1 = never pay above on-demand; evict on capacity. Deallocate eviction policy preserves the node for restart. For a POC the occasional eviction IS the resilience test.

save $$$ Spot scales to zero

spotMinCount: 0 means the pool literally costs nothing while idle. First pod scheduled triggers cluster-autoscaler scale-up (a few minutes of Pending is normal and expected).

free Free control-plane tier

SLA isn't needed to validate the architecture. Flipping to Standard tier later is a one-flag Day-1 change (tier: 'Standard' in aks.bicep).

cap LAW daily quota

dailyCapGb: 1 is a hard ceiling on log ingestion cost - the #1 way POCs accidentally burn money. Raise deliberately, never discover.

Single ACRKeep non-prod only; promote via retag instead of re-importSaves ~$5/mo; weaker supply-chain boundary

6.4 Guardrails to set on day 1

  • Budget: Cost Management → Budgets → e.g. $100/mo with alerts at 50/80/100% to your email.
  • Tags: every resource carries project/environment/costProfile so Cost Analysis pivots cleanly.
  • Review cadence: weekly Cost Analysis by resource group; spot pool actual spend vs estimate.
  • Cleanup path: az group delete on the three RGs removes everything (KV soft-delete survives 7 days by design - purge it if you want the name back).
