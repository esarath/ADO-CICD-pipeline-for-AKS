What this package contains

A complete, ready-to-execute implementation of the reference architecture: two AKS clusters (staging + production), two Azure Container Registries (non-prod + prod), Key Vault, Log Analytics, Managed Prometheus, Managed Grafana, Defender for Cloud, and a 4-pipeline Azure DevOps flow (PR → CI → Promote → CD) with Helm and an ArgoCD GitOps alternative. Every compute choice is deliberately sized small and uses Spot node pools to protect a personal pay-as-you-go budget.

Execution order (TL;DR)

  1. Read doc 02 once, end to end.
  2. Complete Pre-flight tasks §0 in doc 02 — set globally-unique names in the Bicep param files and plan the exact names Azure DevOps will use (service connection, variable group, environments).
  3. Run scripts/00-prerequisites.ps1 (tools + login + providers).
  4. Run scripts/01-deploy-infrastructure.ps1 (~15-20 min).
  5. Run scripts/02-post-deployment-config.ps1.
  6. Follow scripts/03-azure-devops-setup.md in the Azure DevOps portal.
  7. Open a test PR → watch PR → CI → Promote → CD flow.
