3.3 Image promotion strategy

Promotion is a copy of a digest, never a rebuild. The CI pipeline is the only writer to the non-prod registry; the Promote pipeline is the only writer to the prod registry. This makes the prod registry's contents a direct, auditable record of "what passed validation".

CI pushes :42, :9f1a2b3, :dev-latest→ Promote: az acr import :42 → prod ACR as :1.4.0 + :1.4.0-prod→ Tags locked (--write-enabled false)→ CD deploys :1.4.0

Why az acr import

  • Server-side copy - no pull/push through the agent, no egress cost, seconds not minutes.
  • Preserves the digest, so "the bits that were scanned" are the bits deployed.
  • No Docker daemon or registry credentials needed on the agent - pure ARM/Entra auth.

POC runs all pre-prod rings as namespaces on the single dev cluster to save cost; the pipeline contract (tag + values file + environment) is identical, so adding dedicated clusters later is config, not redesign.

3.4 Versioning & release strategy

  • Semver is the only prod-facing version: MAJOR.MINOR.PATCH.
  • Chart version (Chart.yaml) bumps when manifests change; appVersion tracks the app semver.
  • Git tag v1.4.0 on the merge commit = the audit anchor; prod ACR tag 1.4.0 mirrors it.
  • Immutability: prod tags are locked post-import; to "change" a release you promote a new tag - history is append-only.
  • Rollback: redeploy previous semver tag (instant, deterministic) - never rebuild.

3.5 Pipeline wiring notes

  • Secrets: AzureKeyVault@2 task fetches * secrets at job start using the WIF service connection; the SP needs Key Vault Secrets User on the vault (grant it during script 03 setup).
  • Agents: Microsoft-hosted ubuntu-latest. If your private project lacks a free parallel job, request the free grant or run a self-hosted agent (spot B2s VM, ~$6/mo - script 03 §7).
  • Approvals: enforced on the aks-production Environment, not in YAML - so the gate is auditable and can't be edited away by a pipeline change.
  • Chaining: add a resources.pipelines trigger on the CD pipeline to auto-run it after Promote succeeds (kept manual for POC control/cost).
