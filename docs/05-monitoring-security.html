5.2 Grafana quickstart

  1. Open the Grafana endpoint (output of the platform deploy, or az grafana show -g rg-hexaks-platform -n grafana-hexaks-001).
  2. Dashboards → Browse → Managed Prometheus folder ships out-of-box AKS dashboards (node, pod, cluster overviews).
  3. Add Log Analytics as a datasource for log panels (already have Monitoring Data Reader via the Bicep role assignment).

5.3 Useful KQL (Log Analytics)

// Pods not Running in the last hour
KubePodInventory
| where TimeGenerated > ago(1h)
| where PodStatus != "Running"
| summarize by PodName, Namespace, PodStatus

// Container restarts (OOMKill / crashloop detection)
KubePodInventory
| where TimeGenerated > ago(6h)
| extend restarts = toint(PodRestartCount)
| where restarts > 3
| project TimeGenerated, Name, Namespace, PodStatus, restarts

// API audit - who deleted what
AzureDiagnostics
| where Category == "kube-audit"
| where log_s has "delete"
| project TimeGenerated, log_s
| take 50

5.4 Security controls in this build

Identity

  • Entra-integrated AKS with Azure RBAC for Kubernetes
  • Workload Identity (OIDC) for pod → Azure auth - no secrets in pods
  • WIF service connection - no stored SP secrets in Azure DevOps
  • KV CSI driver mounts secrets at runtime (Secrets User role only)

Workload hardening

  • non-root, read-only root FS, dropped capabilities, seccomp
  • Pod Security Standards baseline enforced on app namespaces
  • Default-deny NetworkPolicies + per-app allow rules
  • Resource requests/limits + HPA on every workload

Supply chain

  • Gitleaks, pip-audit, Trivy fs in PR; Trivy image gate in CI
  • Immutable prod tags; digest-preserving promotion
  • ACR admin user disabled; pull only via AcrPull RBAC
  • Defender image vulnerability assessments in registry + runtime

Platform

  • Azure Policy/Gatekeeper addon for guardrails
  • Auto-upgrade: patch channel + NodeImage OS updates
  • Ephemeral OS disks, Azure Linux nodes (small attack surface)
  • Defender for Containers runtime threat detection

5.6 Day-2 ops routine

  • Weekly: review Defender recommendations; check cost in Cost Analysis; review failed pipeline runs.
  • Per release: Promote pipeline → CD staging → acceptance → approve prod env.
  • Monthly: confirm AKS patch-channel upgrades landed; rotate nothing (no secrets stored!) but review RBAC.
  • Before long idle periods: az aks stop dev cluster (doc 06).
